Real Leonida

The open world is real.

GTA 6's Leonida is built on Florida. Play through it on real data: pick a character, explore the map, check the difficulty, run the missions, survive a hurricane season. Then flip to Dev Mode to see how a game data analyst would break the same world down.

        How this was built

        • Pipeline: GitHub Actions downloads 6 public sources, runs 16 data-quality checks and the tests, rebuilds every number and redeploys the site. Code: github.com/Lrk777/real-leonida.
        • Region → county matching follows press map guides (PC Gamer, GTABase, GTABoom). It's a judgement call: the game isn't a 1:1 map, and Mount Kalaga (a mountain) has no real Florida equivalent, so its match is low confidence.
        • Hurricanes: NOAA HURDAT2 best tracks. A county is "hit" when a storm's track, interpolated hourly, passes within 60 nautical miles of the county's centre at hurricane strength (≥64 kt), 1950-2025. Landfall counts use HURDAT2 landfall records since 1851 (distinct storms).
        • Sinkholes: Florida Geological Survey subsidence reports, placed by coordinates. Most aren't field-verified.
        • Alligators: iNaturalist research-grade observations via GBIF, as alligators per 10,000 wildlife observations (so it doesn't just measure where people are).
        • Homicide and road deaths: County Health Rankings 2025 (CDC death records, multi-year averages). Small counties are suppressed by the source and shown in grey.
        • Home prices: Zillow Home Value Index (mid-tier). Context only.
        • Difficulty: each hazard is turned into a percentile among Florida's 67 counties and averaged; ★ = every 20 points. Biomes: k-means on those percentiles, k picked by silhouette score. Survive: 10,000-run Monte Carlo with Poisson hurricanes. PvP: rate ratios with 95% confidence intervals. Missions: names and chapters from fan walkthrough lists (KeenGamer, PC Gamer); summaries are our own words.
