# Real Leonida: is GTA 6's Florida exaggerated?

GTA 6 is set in Leonida, a parody of Florida. This project matches each of the game's six regions to the real Florida counties behind them and measures five kinds of real-world chaos for all 67 counties: hurricanes, sinkholes, alligators, homicide and road deaths.

Findings and the live dashboard are added after the first full data run.
